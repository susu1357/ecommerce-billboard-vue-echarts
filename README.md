# 电商销售可视化看板（Vue3 + ECharts）
> 数据分析师前端可视化实战项目，用于求职作品集展示

## ✨ 项目简介
基于 OnlineRetail 公开电商数据集，实现销售数据BI看板。
前端使用 Vue3 + ECharts，完成多指标切换、折线图、饼图、柱状图可视化，支持图表一键导出PNG图片。
适合数据分析、BI可视化方向简历项目。

## 🛠 技术栈
- Vue3（组合式API）
- ECharts 图表库
- 原生JS、CSS行内样式
- Git + GitHub 版本管理

## 📌 功能清单
1. 指标下拉切换：销售额 / 订单数量 / 客户数量
2. 月度趋势折线图，自定义线条配色
3. 饼图、柱状图多维度数据展示
4. 每个图表独立【导出图片】按钮，下载高清PNG
5. 卡片式布局、柔和商务配色，看板美化
